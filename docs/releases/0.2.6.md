# Explain-to-Me 0.2.6 — Linux preflight repair

**Source release · 2026-10-30 · tag `v0.2.6`**

`doctor` now accepts Linux when its required Kokoro, media-tool, and rendering-browser checks pass. Previously, the platform check rejected Linux even though the Kokoro build path could run there. This patch adapts the Linux proposal to the Windows-aware checks introduced after 0.2.0.

## Changes

- Accept Linux alongside macOS and Windows x64 in preflight.
- Keep Kokoro required on Linux, including its synthesis smoke check. Missing prerequisites still cause failure.
- Give Linux setup guidance for Kokoro, FFmpeg/ffprobe, and the browser, with prepared-manifest or template direction.
- Preserve macOS Apple speech and Windows setup behavior.
- Add focused Linux platform and narrator-selection regression coverage.

See the [Linux setup guide](../linux.md) for exact installation, doctor, build, and private-workspace commands. The [README](../../README.md) retains the macOS and Windows quickstarts. General pacing, project configuration, and music remain with the separate 0.3 work.

## Validation and scope

The new regressions failed against the 0.2.5 code on Linux, reproducing the platform rejection and Windows-only Apple-backend guidance. They pass with this patch.

| Environment | Typecheck | TypeScript tests | Python agent/bridge/setup tests |
|---|---|---|---|
| Windows x64, Node 24.22.1, Python 3.11 | Passed | 101 passed, 5 skipped | 33 passed, 1 skipped |
| Ubuntu 20.04.6 x64 under WSL2, Node 24.22.2, Python 3.11.18 | Passed | 94 passed, 12 skipped | 29 passed, 5 skipped |

Windows checks used `node node_modules/typescript/bin/tsc --noEmit`, `node --import tsx --test 'packages/*/src/*.test.ts' 'apps/*/src/*.test.ts'`, and `node scripts/test-agent.mjs`. Linux used pnpm 10.18.3 with `pnpm typecheck`, `pnpm test`, and `pnpm test:agent`. Skips cover platform-specific privileges/features and opt-in media checks. `git diff --check` passed. Independent source review found no actionable defects.

No fresh Linux media render or native macOS run was performed for this preflight-only change.

The original report describes a 61-second Arch Linux x64 Kokoro build with all 11 automated media gates passing. That is contributor-reported evidence from 0.2.0, not a new media render performed for this patch. Static and regression checks do not establish human watch/listen approval or support for every Linux distribution and architecture.

The later audio-playback report in the issue remains separate: this patch changes no synthesis, sample-rate, channel-layout, timing, rendering, or mux behavior. Optional Claudia/Chatterbox retains its documented Windows/CUDA validation scope.
