# Explain-to-Me 0.3.0 — Review the script, choose the pace, add music

**Source release · 2026-10-30 · tag `v0.3.0`**

Save a local project, review and edit its script before speech synthesis, audition
narration, and build a captioned video with optional local music. Existing
Apple/Kokoro commands and optional animated Claudia remain supported.

## Try it

Start from the tagged source with Node.js 24+ and Git:

```sh
git clone --branch v0.3.0 --depth 1 https://github.com/TommyAllsup/explain-to-me.git explain-to-me-v0.3.0
cd explain-to-me-v0.3.0
```

Follow the [Windows setup](../windows.md) or [macOS quickstart](../../README.md#macos-quickstart-roll-your-first-tiny-movie), then:

```sh
node scripts/create-example-project.mjs --output out/measured-walk
node scripts/explain.mjs plan --project out/measured-walk/project.json --output out/measured-walk/plan
```

Read and edit `out/measured-walk/plan/manifest.json`. Set both `narration.backend` and `narration.voice`
in `project.json`: `kokoro` / `af_heart` or `apple` / `Samantha`. Then:

```sh
node scripts/explain.mjs preview --project out/measured-walk/project.json --plan out/measured-walk/plan --output out/measured-walk/preview
node scripts/explain.mjs build --project out/measured-walk/project.json --plan out/measured-walk/plan --output out/measured-walk/movie
```

The example deliberately slows one passage. Remove its passage override for
normal pace throughout. Kokoro Heart at normal speed was the maintainer's
preferred delivery in the release review; slower pacing remains optional.

## Behavior

- Versioned, bounded project JSON binds a local source or manifest, direction,
  voice, pronunciations, pacing, one music track and output settings.
- Planning saves an editable manifest, source/direction provenance and copied
  approved images without speech or frames. Preview shares production text
  preparation, pronunciation, pacing and speech caches.
- Passage pacing overrides scene pacing, which overrides project pace. Stable
  reviewed passage identities survive sentence splitting. Measured speech drives
  captions and video duration. Strict duration checks are opt-in and fail with
  recovery guidance without rewriting, retiming, truncating or padding speech.
- Optional connected Kokoro delivery uses scene context and measured passage
  boundaries; preview extracts exactly the same cached samples as production.
- One local WAV/MP3/M4A/AAC/FLAC/OGG track supports gain, narration ducking and
  start/end fades. Short tracks end once; looping and crossfades are deferred.
- `audio.wav` remains narration. `music.wav` is the processed music stem,
  `mixed.wav` is the mixture, and the MP4 uses the mixture. Music-only edits reuse
  speech and frames. New outputs preserve preceding cuts.
- Music hashes and supplied rights text record provenance, not automatic
  clearance. Saved-project images must remain within canonical project/plan
  roots; external `assets` symlink escapes are rejected.
- Legacy commands retain duration fitting. Claudia uses the optional
  Chatterbox/Bella setup at natural pace 1, without Kokoro delivery settings.

## Validation and limits

The [verification record](../benchmarks/0.3-project-results.md) records macOS
Apple/Kokoro plan/edit/preview, normal/slower builds, music-only reuse, strict
failure and preserved outputs. Typecheck and media-enabled regressions passed
145 TypeScript tests with 10 platform skips; Python suites passed. A GPT-6.1 Sol
high review found the image-boundary defect above and confirmed its correction,
with no remaining actionable findings in the reviewed scope.

The maintainer approved Kokoro Heart's voice, the slower-passage behavior and
music balance, and prefers normal speed. This feedback does not assert separate
full visual/caption approval. Automated QC remains distinct from human review.

The [Windows merge record](../benchmarks/0.3-claudia-merge.md) covers Kokoro and
Chatterbox project builds and cache reuse. The latest boundary correction was
exercised natively on macOS; Windows/Linux CI provides regression coverage, not a
new native-media acceptance claim. macOS Chatterbox was unavailable locally.

Output remains technical-whiteboard at 720p/24 fps, with optional Claudia.
Whole-process no-egress proof, native Windows local AI direction, ARM64 Windows,
1080p, general cartoon authoring, new input formats and a Studio UI remain
outside this release. The legacy Python job launcher has no project/plan job
contract; agents invoke the project CLI directly. Project code is MIT; model,
voice, dependency and supplied-asset terms remain separate.
