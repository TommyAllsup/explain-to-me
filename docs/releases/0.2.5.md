# Explain-to-Me 0.2.5 — Claudia joins the app

Development integration on `codex/claudia-0.2.5`. No public tag or release has been created by this work.

Claudia can present an ordinary reviewed manifest or template-directed document. The normal CLI synthesizes her selected Bella-reference Chatterbox voice, measures word and phoneme timing, derives lip sync and facial/body acting, and renders her beside supported teaching scenes. A bespoke story script is no longer needed.

## Try it

Complete the app setup and [optional local Claudia setup](../claudia-setup.md), then run:

```sh
node scripts/explain.mjs build --manifest fixtures/presenters/claudia/animated-story.json --output out/claudia-app
```

For another story, use `--presenter claudia` or set `visual.presenter` to `{"character":"claudia"}` on selected title, statement, bullets, or outro scenes. Set `motion` to `"reduced"` for quieter body movement. See [the full workflow](../claudia.md).

## Behavior

- The selected original English Chatterbox profile and frozen Bella reference supply fresh speech. Model/reference hashes and local runtime provenance are recorded.
- New word/phoneme timing is bound to exact PCM bytes. Lip sync uses phonemes and audio energy; phrase timing drives gaze, expressions, and connected gestures.
- Chatterbox speaks at natural speed. Requested duration guides document direction and remains advisory for a fixed script. Reports and QC distinguish requested duration from the measured timeline.
- Speech and alignment are cached together. Derived animation and production rig sources participate in render cache identity.
- `doctor` reports optional readiness. Builds never install or fetch the models. Missing setup or incompatible voice/backend choices produce actionable errors.
- Existing still-image packs, Apple/Kokoro narration, captions, local asset handling, and scene layouts remain supported. Automatic backend selection for builds without animated Claudia retains its existing behavior.

## Boundaries

Local acceptance passed the normal three-scene CLI build and a saved-manifest rebuild with identical audio/video and full cache reuse. Typecheck, 100 TypeScript tests, and 33 Python tests passed; platform/opt-in skips are listed in the [validation record](../benchmarks/claudia-0.2.5.md).

Claudia is an optional local dependency, with Windows x64/CUDA as the initial validation target. The existing app's macOS support does not imply validation of this Chatterbox runtime on macOS. Exact setup and acceptance evidence are documented separately.

Automatic acoustic alignment can be imperfect, and phrase acting is heuristic. Review the finished movie before sharing. This iteration adds neither a desktop editor nor general character authoring. Project configuration, general pace/audition controls, music mixing, stems, and soundtrack-only rebuilds stay with 0.3.

The original auditions and Ben explainer remain historical artifacts. The reusable production path imports no Ben script, soundtrack, or fixed audition timing.
