# 0.2.5 — Claudia in ordinary builds

Owner direction, 2026-10-22: finish the character experiment and integrate the
accepted Claudia voice and animation into the app as 0.2.5. Version 0.3 remains
the separate narration/music product work. This plan authorizes the bounded
integration below; it does not imply publishing a tag or release.

## Product behavior

An ordinary reviewed manifest or template-directed document can opt into an
animated Claudia presenter. Supported teaching scenes retain the existing
reserved presenter panel, caption space, local asset rules, and attribution.
Claudia uses the accepted Bella-reference Chatterbox voice and newly measured
word/phoneme timing for each script. Existing builds and still presenters retain
their behavior. There is no Ben-specific script, visual, or soundtrack dependency.

Chatterbox speaks at natural speed. The requested duration guides direction but
is advisory for this backend; reports distinguish requested from measured time.
Media validation still checks the complete measured audio/video/caption timeline.
Builds never install or fetch model assets silently.

## Implementation boundaries

1. Extend the presenter intent with an animated Claudia variant, preserving the
   existing local still-image variant. Add normal CLI and agent-wrapper support.
2. Add a local Chatterbox adapter with explicit setup/readiness, pinned voice
   reference and model identity, cached speech plus alignment, and bounded bridge
   inputs/outputs. Bind alignment to the exact PCM chunk it describes.
3. Promote the reusable SVG rig, lip shapes, posture, and facial interpolation
   into production packages. Derive restrained phrase gestures from arbitrary
   narration; do not import the fixed audition or Ben story builders.
4. Pass derived animation through the renderer boundary. Include animation and
   every promoted source in render cache identity; retain local-only rendering.
5. Document optional setup, a neutral example, provenance, supported-platform
   evidence, and the release boundary. Bump the development package to 0.2.5.

## Acceptance

- Existing non-presenter and still-presenter tests remain green.
- A neutral three-scene manifest builds through the normal CLI with fresh speech,
  lip sync, gestures, captions, attribution, and the standard media checks.
- Missing prerequisites and incompatible voice choices fail before expensive work.
- Changed text, voice/model identity, alignment, or rig cannot reuse stale caches.
- A warm build reuses unchanged speech and rendering.
- Malformed or mismatched alignment is refused; pronunciation substitutions
  affect spoken timing without changing the visible caption text.
- The experiment videos remain available as historical review artifacts.

## Reserved for 0.3

Project configuration, general narration pacing and audition controls, music
import/ducking/fades, stems, and soundtrack-only rebuilds remain separate. This
slice introduces the fixed Claudia voice and presenter workflow, not those
broader controls or a desktop editor.
